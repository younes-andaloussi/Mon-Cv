# Mon CV interactif

Ce dépôt contient le code source de mon CV en ligne, développé dans le cadre de
mon parcours en Bachelier en Informatique de Gestion.

Il a été conçu comme une vitrine professionnelle et interactive présentant mon
profil, ma formation, mes expériences, mes certifications et mes compétences
techniques.

## Un CV relié à mes projets GitHub

La section **Compétences** du CV ne se limite pas à une liste de connaissances.
Chaque compétence cliquable renvoie vers un projet, un exercice ou un travail
disponible dans mes autres dépôts GitHub.

Ces réalisations ont été effectuées en classe au fil de mon bachelier et
permettent d'illustrer concrètement la manière dont j'ai appris et mis en pratique
les compétences présentées. Elles témoignent également de mon évolution, année
après année, dans différents domaines : programmation, algorithmique, bases de
données, analyse, développement web, systèmes et réseaux.

Ce CV sert donc de point d'accès central vers les travaux qui composent mon
parcours académique sur GitHub.

## Objectifs du projet

- Présenter mon profil, ma formation et mon expérience professionnelle ;
- Donner accès aux réalisations présentes dans mes autres dépôts GitHub ;
- Montrer l'évolution de mes compétences techniques au fil des années ;
- Relier chaque compétence à des travaux qui démontrent sa mise en pratique ;
- Développer et améliorer progressivement mon CV avec les connaissances acquises
  durant ma formation.

## Technologies utilisées

- HTML5
- CSS3
- Git et GitHub
- GitHub Pages
